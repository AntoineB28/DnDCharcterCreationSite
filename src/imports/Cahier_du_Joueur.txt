CAHIER DU JOUEUR - MIDIAN

=== RÈGLES DE BASE ===

STATISTIQUES:
- Intelligence: Observation, déduction, sorts
- Foi: Rituels religieux, miracles
- Charisme: Persuasion, tromperie, intimidation
- Dextérité: Armes légères (couteaux, arcs, sabres, lances), discrétion, acrobatie
- Force: Armes lourdes (masses, marteaux, haches, épées), actions physiques
- Vitesse: Initiative, course rapide
- Constitution: PV = 2x constitution, résistance aux poisons/magie
- Résistance: Résistance saignement/projections/assommage, AC

Bonus/Malus: +1 tous les 2 points au-dessus de 10, -1 tous les 2 points au-dessous

REPOS:
Long rest = récupération PV + ressources magiques

DÉS:
- Attack/Saving throws: D20
- Avantage: Rouler 2d20, prendre le plus haut
- Désavantage: Rouler 2d20, prendre le plus bas
- Dégâts: Notation XdY (ex: 2d8 = lancer 2 d8)

TYPES DE DÉGÂTS ARMES:
- Contondant (masses, marteaux)
- Tranchant (épées, haches)
- Perçant (lances, flèches)

TYPES DE DÉGÂTS MAGIQUES:
- Élémentaires (feu, glace, électricité)
- Spéciaux (psychique, divin, nécrose)

=== CRÉATION DE PERSONNAGE ===

ATTRIBUTION STATISTIQUES:
Base: 8 dans chaque stat
Points disponibles: 28 (max +8 dans une stat)

COMBAT:
Initiative: D20 + bonus vitesse

TOUR DE COMBAT:
- 1 Mouvement
- 1 Action
- 1 Action bonus

ACTIONS POSSIBLES:
- Sprint (double mouvement)
- Attaquer avec arme principale
- Lancer un sort
- Invoquer un miracle
- Lancer quelque chose
- Utiliser une habileté (action)

ACTIONS BONUS:
- Attaquer avec arme secondaire
- Boire une potion
- Parler/crier
- Utiliser une habileté (action bonus)

ATTACK ROLL:
D20 + bonus stat appropriée (force/dextérité/intelligence/foi)

COUP CRITIQUE:
Attack roll = 20 → Dégâts doublés

DÉGÂTS:
Rouler dés + bonus stat appropriée

MORT:
PV = 0 → Down
Down: Constitution saving throw (difficulté 10) chaque tour
- Échec: 1 X
- Succès sans X: Stabilisé (inconscient)
- Succès avec X: -1 X
- 3 X: Mort

- Foi +2, Constitution +1, Dextérité +1

=== CLASSES ===

GUERRIER (Niveau 1-20):
Compétence: Toutes armes rapprochées, toutes armures, boucliers

Niveaux clés:
- 1: Choix arme/armure, Second souffle
- 2: Action surge
- 3: Spécialisation (Barbare/Défenseur/Double-maniement)
